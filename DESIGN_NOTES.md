# Design and content notes

The redesign uses warm ivory, charcoal and orange; large editorial type; custom CSS system diagrams; project filters; expandable technical details; and an animated intelligence sculpture. Responsive navigation and reduced-motion support are included. No stock portraits or invented project screenshots are used.

Visual references reviewed on 5 September 2026:

- [HYDRA](https://hidra.me/): bold typography, restrained composition, and considered motion.
- [ITom](https://itomdev.com/): interactive developer portfolio storytelling.
- [Awwwards portfolio inspiration](https://www.awwwards.com/inspiration/scroll-portfolio): hierarchy and scroll-led presentation.

The implementation is original; no reference-site code or assets were copied.

Content comes from the supplied portfolio and the main/alternate LaTeX resumes. The main resume is preserved at `public/resume.tex`; `public/resume.pdf` is a formatted downloadable version, generated by `scripts/generate-resume.py` using Python ReportLab. Outcome metrics describe the supplied resume's research/project results; they are not independent benchmarks.

The resume versions disagree about alert-review reduction (80% achieved versus 50% targeted), so that metric is omitted from the website. The main PDF preserves the main resume's claim. Teaching-assistant experience was mentioned in the original requirements but had no supporting role details in either resume, so it was not invented. GitHub links point to the supplied profile where no repository URL was provided.
